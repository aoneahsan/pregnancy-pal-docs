# Food

Every food is grouped as enjoy, limit or avoid. Where a rule comes from someone, we name them. Filter by group, or see only what you've kept.

Mark what you don't eat, or an allergy, once. The list changes to match. We don't set calorie targets.

Check any new supplement or big change with your doctor.
